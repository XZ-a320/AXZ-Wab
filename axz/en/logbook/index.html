What .axzlog is

The file starts with the six ASCII bytes AXZLOG, followed by gzipped UTF-8 JSON. The browser can unzip that on its own, so this page needs no server.

The old log system

The old flight log page needed a server: pilots uploaded .axzlog files, they were stored there, and everyone downloaded them. This site is static and has no such server, so files are read in your own browser instead. The wording from the old page is kept below for the record.
