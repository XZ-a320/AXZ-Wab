What .axzlog is

The file starts with six ASCII bytes, AXZLOG, followed by gzip-compressed UTF-8 JSON. Browsers can decompress that on their own, so this readout desk does not need a server.

Pilot Login

This is a decorative door. The site is static, with no server and no account database, so nothing you type here is sent, stored or checked. Please do not enter a password you actually use. Type anything you like and you are in.
