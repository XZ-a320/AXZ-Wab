Accessibility Statement

This site aims to meet WCAG 2.2 Level AA.

Current status

This is a static site. All content is present when the page loads and can be read without scripts. Every interactive element is a native button or link and works with a keyboard. The Chinese and English versions are each marked with their language.

How it was tested

Keyboard walkthrough of every page; proofread with VoiceOver; automated checks with axe-core; contrast calculated one value at a time using the WCAG formula rather than estimated; checked on a real device at 375 pixels wide.

Known issues

The route maps are graphics, and the same information is given in the text table right next to them. The April Fools' page keeps its original rough styling, which is part of the content. Animation on that page is off by default and can be turned on manually.

This site respects the system "Reduce Motion" setting. You can also turn animation off at any time with the "Stop animation" button at the top of the page.

Feedback

If you run into a barrier while using this site, please tell us in the guestbook.
