Accessibility Statement

This site targets WCAG 2.2 Level AA.

Current status

This is a static site. Everything is present when the page loads and reads fine with scripts off. Every control is a real button or link and works from the keyboard. The Chinese and English versions each declare their language.

How it was tested

Keyboard walkthrough on every page; proofread aloud with VoiceOver; axe-core automated checks; every contrast ratio computed from the WCAG formula rather than estimated; checked on a real 375-pixel-wide screen.

Known issues

The route maps are graphics, and everything on them also appears in the text table beside them. The April Fools page keeps its original crude styling, which is part of the content; animation there is off by default and can be turned on.

This site follows your system’s reduce-motion setting. You can also switch animation off at any time with the button at the top of the page.

Feedback

If something on this site does not work for you, please say so in the guestbook.
