# 小泽航空 · Air Xiao Ze (AXZ)

虚拟航司 仅用于模拟飞行

网站：[xiaobrook.com/axz/](https://xiaobrook.com/axz/) · English: [/axz/en/](https://xiaobrook.com/axz/en/)

---

## 这次改版做了什么

内容一个字没改。中文是唯一真源，英文版由中文翻译而来。原站的每一句中文都保留在
`axz-src/content/zh.json` 里，`scripts/check-axz-content.mjs` 会逐句核对，少一句就
构建失败。

主要变化：

- **有了字体。** 原站三个页面用了三套不同的操作系统默认字体。现在用 Noto Sans SC、
  Noto Serif SC 和 IBM Plex Mono，按用途和语言分别裁剪到本站真正用到的字形。
- **航路字符串终于用等宽字体了。** 原来 `.map-text { font-family: Consolas }` 这条
  样式写了，但没有用到任何元素上。
- **logo 出现在网站上了。** 原来 `小泽航空.png` 没有被任何页面引用过。
- **弹窗没有了。** 原站有 12 个 `<div onclick>` / `<span onclick>`，键盘和读屏软件
  完全够不到。现在内容直接展开在页面上，所有可点的东西都是真的按钮或链接。
- **备注栏。** 这是整个设计的骨架，来自 C# 飞行日志记录器里的两个「备注」字段
  （各带一个「无」的勾选框）。「重大事件」和「搞笑黑历史」并排放在同一条基线上。
- **判读台。** `.axzlog` 就是 6 个字节的 `AXZLOG` 加一段 gzip 压缩的 UTF-8 JSON，
  浏览器能直接解开，所以不需要服务器。文件不会上传到任何地方。

## 2026-08-15 加的几块

原来的站只是把这家航司写下来，没有一处能动手。这次加的都是"动词"，一个字的原文都没改。

- **航线网络图**（首页 01 里）。两条航线画在同一个比例尺上，110 公里和 280 公里
  的差别在图上是真的长度差。方位角是用四个机场的真实坐标算的，长度用的是本站
  自己公布的距离——不是重算的大圆距离，不然图会跟旁边的文字打架。点一条航段，
  图和进程单一起标出来。
- **航班时刻表**（首页 03）。四个航班号，加两个基地的实时当地时间。状态栏只有
  "准点"一种值：本站没有任何一处写过起飞时刻，编一张时刻表出来就是造假；这家
  航司公布过的是一句 FLY ON TIME，那就只印这一句。
- **签派台**（`/axz/dispatch/`）。选航段和飞机，出一份放行单，可以下载成纯文本。
  上面每个数都是航线那一节已经有的，只有平均地速是距离除以时间算的，算式印在
  页面上。**不给油量**：算油要全重、风和备降场，本站一样都没有。
- **落地评分**（签派台页面下半部分）。拉平的时机决定接地垂直速度，评语直接用
  机队档案里现成的说法（跑道按摩师 / 跑道震动器 / 重着陆），不新编。空格键就能
  玩，评分标准是一张服务端渲染的表，不开脚本也在。
- **资源与联动**（首页 06）。站外链接，加一份 B-1717 的涂装档案——照片那一栏
  写"无"，用的就是记录程序自己的空值规矩。
- **飞行模拟**（`/axz/sim/`）。浏览器里的 3D 飞行模拟，键盘和手柄都能飞。
  气动是按系数算的：升力随迎角变、会失速、失速后会掉翼尖，发动机推力有延迟，
  起落架是弹簧阻尼加轮胎摩擦，尾撬会擦地。飞机的尺寸直接取自
  `scripts/airframe.mjs` 里那张表——首页画俯视图用的是同一组数字，所以 A321
  在这里也比 737 长。地形是程序生成的，两个机场、两条跑道、旧金山湾和蒙特雷湾，
  跟航线那一节写的地标对得上。落地按签派台那张表评分，四个档位一字不差。

  **画面。** 天上有积云，地上有树，飞机有影子，尾流、轮胎烟、发动机尾迹和尾迹云
  都是粒子。每一样都跟物理挂钩，不是贴上去好看的：轮胎烟按接地垂直速度放，
  烟越大分越差；翼尖白雾只在机翼接近升力极限时才出现；尾迹云要七千二百米以上。
  贴图全部是启动时用 canvas 画出来的，一个图片文件都不下载——机身上的 AXZ
  字标、尾翼的 FLY ON TIME、客舱舷窗、B-1717 那条方块涂装带，都是画的。

  **光照。** 有真正的阴影贴图：一层级联，跟着飞机走而不是跟着镜头走（塔台视角
  下镜头在一英里外，要紧的影子还在机翼底下），2048²，深度图用正面剔除加坡度
  自适应偏移，采样时 3×3 PCF。光照挪到片元级算，因为顶点级的高光会挂在三角形
  的角上、阴影边会顺着网格走。环境光是半球式的：朝上的面吃天光，朝下的不吃。
  机身有镜面高光，是这个场景里唯一该"反光"的东西。水面按几何判定（全世界只有
  海是平的、水平的、正好在零高度，陆地从二十几米起步），有菲涅尔、波纹扰动和
  太阳耀斑。

  **PAPI。** 跑道左边四盏灯，角度用的真值（2.5 / 2.833 / 3.167 / 3.5 度）。
  四白偏高，四红偏低，两白两红在道上。数据栏里同步写成 W / R。

  **风。** 有平均风、有风切变、有阵风。气动算的是相对气流，所以顶风只改地速不改
  空速，侧风不修正就会飘出中线；近地面风会减速，拉平时的侧风跟五边上不一样。

  **四个航班都能飞。** AXZ001 到 AXZ004，两条航线四个机场。上海和南京那一头
  照着航线那一节写的地标建：长江口、太湖，还有几乎全平的三角洲地形。

  **天空、辉光、爆炸。** 天空是一整块着色器：地平线到天顶的渐变、太阳本体、
  朝阳方向的前向散射，还有贴地的雾带。整个场景先画进离屏纹理，取出亮的部分做
  四分之一分辨率高斯模糊再叠回来，最后过一遍 ACES 色调映射。辉光不是装饰：
  火球的核心亮度是刻意超过 1 的，靠这一步才会"烫"起来，跑道灯和太阳也顺带受益。

  **摔机。** 三种判法，都从物理量来：接地垂直速度超过 1200 英尺/分钟（约等于
  737 起落架设计极限）、接地坡度超过 32 度、或者收着起落架落地。摔了之后机翼
  只剩一成升力、发动机停车、操纵失效，机体翻滚着掉下去，落点起火冒黑烟，
  镜头跟着抖一下。火球分四层：白热核心、外层火焰、烟柱、抛射的碎片，
  外加一圈地面冲击波。

  **声音。** 全部现场合成，一个音频文件都不下载。发动机第一版用锯齿波打底，
  结果是一团低频嗡嗡声，像合成器不像飞机——涡扇的主音根本不在那个频段。现在
  按真实的构成来：宽带排气噪声挑大梁，推力越大频谱开得越高；一层很轻的叶片
  通过频率哨音在一到三千赫兹，这才是耳朵认出"喷气"的那一层；底下垫一层低频
  隆隆。全程跟着 N1 走，所以推力有延迟声音就有延迟——这是采样循环做不到的。
  用 OfflineAudioContext 实测过：过零率从怠速 169 Hz 到爬升 873 Hz，不削顶。
  气流跟指示空速走，放起落架襟翼会更响；地面滚动跟地速走；失速断续告警、
  超速嗒嗒声、接地闷响按垂直速度定轻重；爆炸是噪声爆冲加下扫的次低频加噼啪声。
  音频只在按下"启动模拟器"之后建立（浏览器要求用户手势），而且默认静音，
  要自己点"声音"才开。

  渲染器是自己写的，不是 three.js。这一页要的是平面着色的三角形、线和雾，
  three.js 是 750 KB，整个引擎自己写只有 260 KB——这个站的字体都从 17.7 MB
  裁到 196 KB 了，没道理在这里多背 600 KB。引擎是按一下才下载的，
  不点的话这一页一个字节都不多加载；没有 WebGL 或者没有脚本的时候，
  操作表和评分标准照样是完整的。
- **记录程序改成本站直接下载**（`/axz/downloads/AXZ-FlightLogRecorder.zip`）。
  原来放在 GitHub 的发布页，因为那个 exe 有 107.8 MiB，超过 GitHub 单文件
  100 MiB 的上限，进不了仓库。压成 zip 之后是 42.6 MiB，三个仓库都收得下，
  下载的时候浏览器也不会因为是未签名 exe 而拦一道。**exe 本身还是没签名的**，
  解压出来第一次运行照样会弹 SmartScreen，页面在按钮前面就写清楚了。
  页面上印了 SHA-256，构建时会拿真文件算一遍对不上就报错，大小也是读真文件写
  进去的，不是手打的。
- 顺手删掉了 `pages.css` 里 79 行重复和过期的样式，机头那张图的比例也跟着回到
  1.158（之前被一段旧的 SVG 时代样式挤成了 1.208）。另外补了 `axz/fixtures/`
  的拷贝——构建每次清空输出目录，却从来没把示例日志放回去，所以「载入示例文件」
  那个按钮在任何一次全新构建后都是 404。

## 目录

```
axz-src/          源文件（内容、样式、脚本、字体、图）
  content/        zh.json 是真源，en.json 由它生成
scripts/          构建与校验
axz/              构建产物，直接部署
AXZ-HTML/         原站，保留作为参考
```

## 构建

```bash
node scripts/subset-axz-fonts.mjs   # 需要 fonttools，见 axz-src/fonts-src/README.md
node scripts/build-axz.mjs
```

字体子集已经提交，所以第一步通常可以跳过。

## 校验

五道关，全部要过：

```bash
node scripts/check-axz-content.mjs    # 原站每一句中文都还在
node scripts/check-axz-contrast.mjs   # 29 组对比度实算，不用估值
node scripts/check-axz-en.mjs         # 英文固定译法 + 结构对齐 + 外链地址不许翻译
node scripts/axe-axz.mjs              # WCAG 2.2 AA，14 个页面 × 昼夜两套
node scripts/verify-axz.mjs           # 键盘、判读台、网络图、时刻表、签派台、落地评分、飞行模拟、彩蛋页、双语接线
```

后两道需要先起本地服务：`node .axz-serve.mjs`（端口 4788）。

## 几件不要动的事

- **31100 英尺是对的。** 那是 9,500 米，中国的米制 RVSM 高度层。不要「改正」成
  31,000。`check-axz-en.mjs` 会拦。
- **留言板的三条留言不翻译。** 那是别人写的话，英文版里也保持中文原样，一个字节都
  不改。
- **`跑道震动器` 的英文是 the Runway Shaker。** 直译会翻成很不合适的词。
- **原站的错别字保留。** 「应为防水问题」照原样，这是这个网站的一部分。
- **时刻表不许长出发时刻。** 原站从来没写过任何一个起飞时间，加上去就是编的。
- **签派台不许长出油量。** 同上，没有全重、风和备降场就算不出来。
- **落地评分只用机队档案里已有的评语。** 不要为这个小游戏新写俏皮话。
